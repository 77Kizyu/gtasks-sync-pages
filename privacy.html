Privacy Policy - Claude Tasks Sync

Claude Tasks Sync is a personal tool used only by its developer, on the developer's own computer.

Data accessed

With the owner's consent, the app accesses the owner's own Google Tasks (task lists and tasks) through the Google Tasks API, in order to read tasks, add tasks, and mark tasks as completed.

How data is used and stored

Task data is processed only on the owner's computer and is stored only in local files on that computer. The app has no server and does not collect, transmit, sell, or share any data with third parties.

OAuth credentials and tokens are stored only on the owner's computer and are never published.

Google API Services User Data Policy

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time from the Google Account permissions page (myaccount.google.com/permissions).
